3. Architecture Diagram

Client (Browser)
React 18 + Vite + TypeScript + TailwindCSS
↓ HTTPS / REST / WebSocket
Supabase Auth
JWT sessions, role-based access
Supabase Postgres
RLS policies enforce role model at DB layer
Resend (Email)
Escalation nudges, 100/day free tier
↓
Database Schema
users — Employee/Manager/Admin profiles
cycles — Performance cycles (goal_setting → Q1 → Q2 → Q3 → Q4)
goals — Weighted OKRs with UoM types
checkins — Quarterly progress + auto-scored
audit_logs — Every action tracked
escalation_rules — Configurable nudge rules
escalation_logs — Triggered notification history

Key Design Decisions

  • Zero backend code — All security via Supabase RLS, no Express/Fastify server
  • Free tier only — Vercel + Supabase + Resend, zero hosting cost
  • Role switcher — Demo view lets judges flip Employee/Manager/Admin without logout
  • Auto-scoring — 5 UoM formulas compute scores, eliminating subjective manager bias
