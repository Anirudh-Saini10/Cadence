Cadence

Goal Setting & Performance Tracking Portal
AtomQuest Hackathon 1.0 — Complete enterprise performance management, from goal creation to quarterly analytics.

Live Demo: cadence-growth.vercel.app

The Problem

  • Enterprises track goals in spreadsheets — no version control, no audit trail
  • Managers can't see team progress without manual follow-ups
  • Quarterly check-ins are subjective; scoring is inconsistent across departments
  • Admins have zero visibility into org-wide completion rates

The Solution

Cadence digitizes the full performance cycle:

  1. Admin opens a cycle (e.g., FY 2025-26)
  2. Employees author weighted OKRs with real-time validation
  3. Managers approve or return goals with one click
  4. System auto-advances phases, auto-scores check-ins via 5 UoM formulas
  5. Admin monitors completion, runs escalation nudges, exports analytics

Key Metrics
