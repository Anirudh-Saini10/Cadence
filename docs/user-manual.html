Flow 1: Employee Creates Goals

Step 1: Log in as Employee

1. Visit cadence-growth.vercel.app
2. Click Employee under Demo Accounts (or enter priya@cadence.demo / cadence123)
3. You'll land on the Dashboard

Step 2: Create Goals

1. Click My Goals in the sidebar
2. Click + Add Goal
3. Fill in: Thrust area, UoM type, Target, Weightage %, Goal title, Description
4. Watch the live weightage bar update (orange = incomplete, green = 100%)
5. Add more goals until total weightage = 100%
Validation enforced:
- Total weightage must equal exactly 100%
- Each goal needs at least 10% weightage
- Maximum 8 goals allowed
- Each goal must have a title

Step 3: Submit for Approval

1. Once weightage bar shows 100 / 100% Ready to submit
2. Click Submit for approval
3. Status changes from "Draft" → "Submitted"

Flow 2: Manager Reviews & Approves

Step 1: Switch to Manager

1. Log out → Log in as Manager (manager@cadence.demo)
2. Or if logged in as Admin, use the Demo View switcher (top right) → select Manager

Step 2: Review Team Goals

1. Click Team in the sidebar
2. See list of direct reports (Priya, Arjun)
3. Click an employee name to open their goal sheet
4. Review each goal: title, thrust area, target, weightage

Step 3: Approve or Return

1. Click Approve all to lock all goals at once
2. Or click Return on a specific goal to send it back to draft with a comment
3. Approved goals show a green Locked badge

Flow 3: Employee Records Check-ins

Prerequisite

Check-ins only open when the Admin advances the cycle phase to Q1, Q2, Q3, or Q4/Annual.
If cycle is in "Goal Setting", check-ins page will show "Check-ins are not open yet."

Step 1: Advance Cycle (as Admin)

1. Log in as Admin (or use Demo View switcher)
2. Go to Cycles
3. Click Advance on Q1 to open quarterly check-ins
4. (If needed later, click Reset to Goal Setting to go back)

Step 2: Employee Records Progress

1. Log in as Employee
2. Click Check-ins
3. Enter Actual Achievement for each goal
4. System auto-computes score using the UoM formula
5. Click Save Check-in

Flow 4: Admin Analytics & Governance

Analytics

1. As Admin, go to Analytics
2. View: Total goals, approved count, completion rate by department
3. Charts: Bar chart (dept stats), Pie chart (goal distribution), Line chart (score trends)
4. Click Export CSV to download a report

User Management

1. Go to Users
2. Click Edit to change a user's name, email, or role
3. Click View Goals → Reset to force-return a locked goal to draft

Escalations

1. Go to Escalations
2. Toggle rules on/off (Checkin Overdue, Goal Not Submitted)
3. Edit day threshold
4. Click Trigger Manual Check to run the escalation engine
5. View sent notifications in Escalation History

Flow 5: Demo Data Seeder

1. As Admin, go to Dashboard
2. Find the Generate Demo Data card
3. Click Seed — instantly populates 4 realistic goals for every employee
4. Refresh to see the seeded goals in My Goals / Team pages
Pro Demo Tip: Log in as Admin, click Seed, then use the Demo View switcher to flip between Employee, Manager, and Admin to show the full seeded workflow without any manual data entry.
